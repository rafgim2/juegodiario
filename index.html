Cómo funciona

El reconocimiento y las sugerencias se calculan en este navegador. No necesitas cuenta, API ni backend. Web MIDI requiere HTTPS o localhost y un navegador compatible (por ejemplo, Chrome o Edge). Si abres este archivo directamente, puedes probar con el teclado del ordenador aunque MIDI no esté disponible. La tonalidad es una estimación basada en las notas recientes; los acordes ambiguos pueden tener otras lecturas.

Harmony Copilot · Todo el análisis se hace localmente. La entrada MIDI no se graba ni se envía.
